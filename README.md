# Telegram-бот с умной долговременной памятью (Pinecone)

Бот хранит сообщения пользователя в Pinecone и **не создаёт дубликаты**:
перед записью считается косинусное сходство с уже сохранённым.

| сходство | action | что происходит |
|---|---|---|
| < 0.6 (`SIMILARITY_THRESHOLD`) | `inserted` | новая информация, запись добавлена |
| >= 0.6 | `updated` | вариация — обновлён существующий слот |
| >= 0.97 (`SIMILARITY_SKIP_THRESHOLD`) | `skipped` | почти точный повтор — ничего не пишем |

## Запуск
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env      # впишите ключи Pinecone / OpenAI / Telegram
python pinecone_manager.py  # ручной тест подключения и дедупликации
python bot.py               # запуск бота
python test_offline.py      # проверка логики без ключей (заглушки)
```

## Что сделано
- `pinecone_manager.py` — класс `PineconeManager` (запись/поиск/удаление, создание индекса),
  поддержка `OPENAI_BASE_URL`, умная фильтрация дубликатов, тестовый скрипт в конце файла.
- `bot.py` — бот на pyTelegramBotAPI. Метаданные собираются только из имеющихся полей
  (нет имени/фамилии/username — fallback на `user_<id>`); в память пишется только текст
  сообщения пользователя, без ответов бота. Дубликаты ищутся в рамках одного пользователя.
- Команды: `/start`, `/forget` (стереть память о пользователе).

Примечание: Pinecone serverless — eventual consistency, запись становится видна для поиска
через 1–5 секунд, поэтому две фразы подряд в течение секунды могут обе получить `inserted`.
